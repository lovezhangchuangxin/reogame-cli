## 资源生产机制

### 生产公式

```
产量 = 基础产量 × 等级 × 增长系数^等级 × (1 + 加成)
```

### 能源系统

**能源是所有资源建筑的基础**:

- 能源效率 = 电能产出 / 电能消耗
- 实际产量 = 基础产量 × 能源效率

### 能源管理

**关键指标**:

- 能源效率 >= 80% (正常生产)
- 能源效率 >= 90% (高效生产)
- 能源效率 >= 100% (满效率)

**能源不足时**:

1. 优先升级太阳能电站(103)
2. 建造太阳能卫星
3. 升级聚变反应堆(105)（消耗重氢）
