## 防御策略

### 性价比分析

| 防御       | 战力/成本比 | 推荐场景 |
| ---------- | ----------- | -------- |
| 轻型激光塔 | 1.38        | 量大取胜 |
| 导弹发射器 | 1.23        | 基础防御 |
| 离子大炮   | 1.65        | 护盾杀手 |
| 等离子炮   | 0.99        | 高伤害   |
| 重型护盾   | 6.57        | 护盾保护 |

### 建议比例

**火力配置**: 轻型激光塔 : 离子大炮 : 等离子炮 = 3 : 2 : 1

**护盾配置**: 每50个攻击设施配1个护盾

### 防御原则

1. **数量优势**: 防御性价比来自数量
2. **护盾保护**: 护盾大幅提高生存能力
3. **火力覆盖**: 混合武器类型应对各种敌人
4. **成本控制**: 根据资源量力而行
