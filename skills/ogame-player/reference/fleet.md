# 舰队任务系统

## 任务类型

| 任务 | 代码       | 用途         | 返程   |
| ---- | ---------- | ------------ | ------ |
| 运输 | Transport  | 资源转移     | 自动   |
| 攻击 | Attack     | 攻击敌方行星 | 自动   |
| 驻守 | Defend     | 防御友方行星 | 需召回 |
| 侦察 | Spy        | 侦察敌方情报 | 自动   |
| 殖民 | Colony     | 殖民新行星   | 不返程 |
| 回收 | Recycler   | 回收战场残骸 | 自动   |
| 探险 | Expedition | 宇宙探索     | 自动   |
| 部署 | Deploy     | 部队调动     | 不返程 |

## 飞行时间计算

### 基础公式

```
飞行时间 = (10 + 3500 × √(距离 × 1000 / 速度)) / 加速系数
```

### 距离计算

| 距离类型 | 计算方式          |
| -------- | ----------------- | ------ | --- |
| 同星系   |                   | 位置差 | × 5 |
| 同银河   | 1000 + 银河差 × 5 |
| 跨银河   | 银河差 × 2000     |

### 引擎影响

| 引擎类型   | 速度倍率 |
| ---------- | -------- |
| 燃烧引擎   | 1.0x     |
| 脉冲引擎   | 1.5x     |
| 超空间引擎 | 2.0x     |

**舰队速度取最慢舰船**

## 资源消耗

### 燃料公式

```
燃料 = Σ(舰船基础消耗 × (1 + 等级 × 0.1)) × 距离
```

### 消耗特点

- 出发时扣除
- 返程也消耗
- 召回仍消耗出发燃料

## 各任务详解

### 运输任务

**用途**: 星球间资源转移

**要点**:

- 选择合适速度节省燃料
- 确保货船容量足够
- 可设置返程自动返回

**操作**:

```
1. 选择舰队
2. 目标星球
3. 装载资源
4. 选择速度
5. 出发
```

### 攻击任务

**用途**: 攻击敌方掠夺资源

**要点**:

- 战前必须侦察
- 评估收益/风险
- 确保足够容量装载战利品

**流程**:

```
1. 侦察目标
2. 评估实力
3. 组建攻击舰队
4. 出发
5. 战斗
6. 返程（带战利品）
```

### 驻守任务

**用途**: 协助友方防御

**要点**:

- 舰队参与防御战斗
- 需要时召回
- 消耗驻守方重氢

**时机**:

- 盟友请求支援
- 预警敌方攻击
- 协同防御

### 侦察任务

**用途**: 获取敌方情报

**要点**:

- 间谍卫星专用
- 可能被发现并摧毁
- 技术等级影响信息详细度

**信息获取**:

```
间谍技术等级差 = 己方 - 敌方

+3: 资源信息
+2: 舰队信息
+1: 防御信息
0: 建筑信息
```

### 殖民任务

**用途**: 建立新殖民地

**要点**:

- 殖民船消耗型
- 选择好位置
- 成功后建立新星球

**选址考虑**:

- 资源分布
- 位置战略价值
- 避免敌对玩家密集区

### 回收任务

**用途**: 回收战场残骸

**要点**:

- 需要回收船
- 残骸位置在战场坐标
- 优先回收避免被抢

**时机**:

- 战斗结束后
- 发现残骸报告
- 敌方战损后

### 探险任务

**用途**: 宇宙探索获取奖励

**要点**:

- 有风险（可能损失舰队）
- 可能获得资源/科技点/道具
- 探险技术等级影响效果

**可能结果**:

```
- 发现资源
- 获得科技点
- 发现特殊物品
- 遭遇海盗（战斗）
- 损失舰队（黑洞等）
```

### 部署任务

**用途**: 舰队永久调动

**要点**:

- 舰队不返回
- 停留在目标星球
- 适合舰队重新部署

## Fleet Save (FS)

### 什么是FS

Fleet Save = 舰队保存

- 离线时保护舰队和资源
- 避免被攻击损失

### FS方法

#### 方法1: 运输FS

```
舰队 → 运输到自己的星球 → 到达前召回
```

#### 方法2: 部署FS

```
舰队 → 部署到另一个星球 → 到达前召回
```

#### 方法3: 探险FS

```
舰队 → 探险任务 → 长时间离线时
```

### FS原则

1. **时间覆盖**: 确保离线期间舰队在飞行
2. **召回安全**: 返回时间在预计在线时
3. **资源携带**: 带走所有资源
4. **隐蔽性**: 避免被预判返回时间

## 舰队槽位管理

### 槽位计算

```
总槽位 = 基础槽位 + 计算机技术加成

基础槽位: 通常为 1-3
每级计算机技术: +1 槽位
```

### 槽位分配建议

| 槽位 | 用途        |
| ---- | ----------- |
| 1-2  | 日常运输/FS |
| 2-3  | 攻击任务    |
| 1    | 侦察        |
| 1    | 备用        |

## 舰队调度技巧

### 多线操作

- 同时派出多支舰队
- 错开到达时间
- 最大化效率

### 协同作战

- 联盟成员配合
- 同时到达攻击
- 压倒性优势

### 快速反应

- 保留应急槽位
- 舰队分散部署
- 及时响应威胁
