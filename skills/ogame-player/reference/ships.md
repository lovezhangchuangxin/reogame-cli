## 舰船属性详解

### 攻击力

- 决定对敌人造成的伤害
- 不同武器类型对不同护盾有不同效果

### 护盾值

- 吸收伤害的屏障
- 轻型/中型/重型护盾对不同武器有不同抗性

### 装甲值

- 护盾被突破后的生命值
- 装甲归零舰船被摧毁

### 速度

- 决定飞行时间
- 受引擎类型和科技影响

### 燃料消耗

- 消耗重氢
- 与距离和舰船数量相关

## 舰船解锁条件

### 基础舰船

- **轻型战机**: 造船厂2 + 武器技术2 + 护盾技术2 + 装甲技术2 + 燃烧引擎2
- **小型货船**: 造船厂2 + 护盾技术1 + 装甲技术2 + 燃烧引擎2

### 中级舰船

- **巡洋舰**: 造船厂4 + 武器技术5 + 护盾技术5 + 装甲技术5 + 脉冲引擎3 + 离子技术5
- **战列舰**: 造船厂5 + 武器技术7 + 护盾技术7 + 装甲技术7 + 超空间引擎3 + 激光技术10

### 高级舰船

- **毁灭级**: 造船厂10 + 武器技术16 + 护盾技术14 + 装甲技术14 + 超空间引擎8 + 激光技术19 + 离子技术17
- **战争要塞**: 造船厂10 + 武器技术16 + 护盾技术16 + 装甲技术16 + 超空间引擎8 + 超空间技术10 + 引力子研究1

### 终极舰船

- **黑色流浪者**: 需要毁灭者军官
- **死飞级**: 需要将军军官
- **圣像战舰**: 需要征服者军官
