# 战斗系统

## 战斗基础

### 战斗流程

```
1. 舰队到达目标
2. 战斗开始
3. 回合制交战 (最多6回合)
4. 计算战果
5. 生成残骸
```

### 战斗结果

| 结果     | 条件                |
| -------- | ------------------- |
| 攻击方胜 | 防御方全灭          |
| 防御方胜 | 攻击方全灭或撤退    |
| 平局     | 6回合后双方仍有单位 |

## 伤害计算

### 基础公式

```
伤害 = 攻击力 × (1 + 武器技术加成)

实际伤害 = max(0, 伤害 - 护盾吸收)
```

### 护盾效果表

| 攻击类型  | 轻型护盾 | 中型护盾 | 重型护盾 |
| --------- | -------- | -------- | -------- |
| 标准/激光 | 70%      | 20%      | 0.0015%  |
| 离子      | 60%      | 70%      | 5%       |
| 等离子    | 2%       | 40%      | 55%      |
| 引力      | 2.5%     | 15%      | 70%      |

**解读**: 百分比表示护盾能吸收的伤害比例

### 装甲损伤

```
护盾被突破后:
装甲伤害 = 剩余伤害 / 装甲效率

装甲归零 → 舰船/防御被摧毁
```

## 战斗策略

### 战前侦察

**必须侦察**:

- 敌方舰队数量和类型
- 防御设施数量
- 资源量（评估收益）

**侦察报告解读**:

```
间谍技术等级差距 → 报告详细程度
高1级: 基础信息
高3级: 详细数量
高5级: 精确数据
```

### 兵力对比

**安全攻击比例**:

| 目标         | 推荐优势 |
| ------------ | -------- |
| 无防御资源星 | 1:1      |
| 基础防御     | 2:1      |
| 中等防御     | 3:1      |
| 强力防御     | 5:1+     |

### 舰队配置策略

#### 速攻配置

```
轻型战机 x200 (炮灰)
重型战机 x100 (主力)
巡洋舰 x50 (护盾杀手)
```

#### 重击配置

```
战列舰 x100 (主力输出)
战列巡洋舰 x30 (支援)
行星轰炸机 x10 (破防)
```

#### 混合配置

```
轻型战机 x100 (前排)
战列舰 x50 (中排)
巨型舰船 x3 (后排核心)
回收船 x10 (战后回收)
```

## 战利品计算

### 掠夺比例

```
单次掠夺 = min(舰队容量, 资源总量 × 50%)
```

### 残骸生成

```
残骸 = floor(被摧毁单位成本 × 30%)
```

**残骸组成**:

- 金属: 50%
- 水晶: 50%
- 重氢: 不进入残骸

## 战斗时机

### 最佳攻击时机

- 敌方不在线
- 资源积累较多
- 防御薄弱
- 舰队外出

### 避免攻击的情况

- 敌方在线且活跃
- 防御强大
- 收益低于成本
- 邻近敌方联盟

## 战斗模拟

### 简易估算

```
己方战力 = Σ(舰船数量 × 单体战力 × 科技加成)
敌方战力 = Σ(防御/舰队 × 单体战力 × 科技加成)

战力比 > 2:1 → 安全攻击
```

### 详细模拟步骤

1. 统计双方单位
2. 计算各方总攻击/护盾/装甲
3. 模拟各回合交战
4. 估算双方损失
5. 计算收益是否值得

## 战后处理

### 回收残骸

```
派遣回收船 → 残骸区域 → 回收资源
```

**回收容量**:

```
回收量 = min(残骸总量, 回收船容量 × 50%)
```

### 修理防御

- 防御设施有70%修复率
- 无需额外资源
- 自动修复

### 评估战斗

- 检查实际收益
- 分析战损比
- 总结经验教训

## 特殊战斗技巧

### 闪电战

- 快速出击
- 打完就跑
- 适合掠夺资源

### 围攻

- 持续攻击
- 消耗敌方防御
- 需要充足后勤

### 诱敌

- 故意露出破绽
- 引诱敌方攻击
- 配合联盟反击
