## 资源平衡策略

### 生产比例调整

```
目标比例: 金属:水晶:重氢 = 2:1:1

调整方法:
1. 升级对应建筑
2. 使用市场交易
3. 黑洞转换
```

### 存储管理

```
原则: 不溢出、不空仓

溢出风险 → 升级仓库 / 调出资源
空仓风险 → 调入资源 / 等待生产
```

### 调度原则

```
主星球 → 殖民星: 均衡发展
资源星 → 军事星: 支援建设
军事星 → 前线: 后勤补给
```

## 战斗决策树

```
发现目标
├── 侦察了吗？
│   ├── 否 → 先侦察
│   └── 是 → 评估实力
├── 实力对比
│   ├── < 2:1 → 放弃或增援
│   ├── 2:1 ~ 3:1 → 谨慎攻击
│   └── > 3:1 → 安全攻击
├── 收益评估
│   ├── 收益 < 成本 → 放弃
│   └── 收益 > 成本 → 执行
└── 时间安排
    ├── 能在线到返程 → 执行
    └── 无法在线 → 推迟
```

## 防御策略矩阵

| 资源量 | 防御等级 | 策略         |
| ------ | -------- | ------------ |
| 低     | 低       | 继续积累     |
| 低     | 高       | 减少防御投资 |
| 高     | 低       | **紧急加强** |
| 高     | 高       | 维持现状     |

**高风险组合**: 高资源 + 低防御 = 被掠夺目标

---

## 紧急情况处理

### 被攻击预警

1. **确认信息**: 攻击到达时间
2. **评估实力**: 能否防守
3. **决策**:
   - 能防守 → 准备防御
   - 不能防守 → FS

### 资源短缺

1. **确认类型**: 哪种资源
2. **紧急措施**:
   - 暂停非必要建设
   - 从其他星球调度
   - 市场购买
   - 黑洞转换

### 能源危机

1. **立即升级电站**
2. **建造太阳能卫星**
3. **暂停高耗电建筑**
